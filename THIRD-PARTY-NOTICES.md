## Built with DINOv3

Some example assets in this repository are meshes generated by image-to-mesh models (TRELLIS.2 and
Pixal3D, both MIT) that condition on Meta's DINOv3 image encoder. No DINOv3 weights or code are
distributed here; the credit is given because the assets were made with it. Both mesh workflows
cut the subject out with BiRefNet (MIT) first. The DINOv3 License is copied at
`licenses/DINOv3-LICENSE.txt`.

- `crates/ludion-testkit/tests/fixtures/idol-generated/` — TRELLIS.2
- `examples/gallery/meshes/creature-head-generated/` — Pixal3D

Each asset's mesh document carries an `origin:` block naming the recipe, workflow and models that
produced it. A game built from this repository that ships a generated mesh outside it carries the
same "Built with DINOv3" line in its own credits or about screen.

## rapier3d (vendored, modified)

The physics solver, rapier3d 0.35.3 (Apache-2.0, Dimforge), is vendored under `vendor/rapier3d/` with
one file modified: the angular-limit and angular-motor rows of the joint solver use the exact rate of
the angle they constrain. `vendor/rapier3d/LUDION-PATCH.md` states the modification and
`vendor/rapier3d/LUDION-PATCH.diff` is the change against the pristine release; the Apache license
is at `vendor/rapier3d/LICENSE-APACHE`.
