# UI components

**Scope:** the fields and defaults of the screen-space UI primitives and world `Text`, split out of
`ludion docs components` (registry rules and drift safety live there). The wider topics — the
reference canvas, anchors, draw order, and the selectable-menu widget's cursor/activation/windowing —
are `ludion docs screen-ui` and `ludion docs ui-list`.

| Component | Fields (default) |
|---|---|
| `UiRect` | `anchor` (`Anchor::TopLeft`), `offset: [f32;2]` (`[0,0]`, canvas units, **+Y down**) — the reference-canvas placement `UiText`/`UiList` also use, `size: [f32;2]` (`[100,100]`; a non-positive axis is `L1118`), `texture: Option<String>` (none → flat-colored quad) + `atlas: Option<String>` + `frame: Option<String>` (set together, never beside `texture`: `L1151`), `color: [f32;4]` (white), `order: i32` (`0`), `visible: bool` (`true`), `rotation: f32` (`0`, degrees clockwise on screen about the rect centre; non-finite is `L1620`), `uv_rect: Option<[f32;4]>` (none — the `[u0,v0,u1,v1]` sub-rect sampled), `slice: Option<UiSlice>` (none — nine-slice `{border: [l,t,r,b] texels, scale (1), center (stretch|hidden)}`; wins over `uv_rect`; bad numbers `L1612`, ignored `L1613`, clamped `L2301`; see `ludion docs ui-nine-slice`) — a screen-space colored or textured rect, anchored to one of the canvas's nine points. See `ludion docs screen-ui` |
| `UiText` | `anchor` (`Anchor::TopLeft`), `offset: [f32;2]` (`[0,0]`, canvas units, **+Y down**), `text: String` (`""`), `size: f32` (`24.0`, glyph cell height; a non-positive value is `L1118`), `color: [f32;4]` (white), `order: i32` (`0`), `wrap_width: f32` (`0.0` = no wrap — greedy word-wrap otherwise, breaking at spaces and tabs and after `-`/`—` (never at U+00A0), hard-breaking an overlong word; `\n`, `\r\n` and `\r` are paragraph breaks), `font: Option<String>` (none → the table's `default`, else the embedded 8×8 face; `L1254` if unnamed in `fonts.yaml`), `visible: bool` (`true`), `rotation: f32` (`0`, as `UiRect`), `key: Option<String>` (none: a `kind: strings` key resolved in the active locale into a runtime-only `resolved` string that layout and draw read through `shown()`; `text` stays the authored fallback and is never rewritten), `args: {name: value}` (empty: the key's `{name}` placeholders, set by `localization::set_text_args`; see `ludion docs localization`) — a run of screen-space text, sharing `UiRect`'s coordinate model and pivot rule. See `ludion docs screen-ui`, `outline: Option<{width, color}>` (none; ink under the glyphs, `ludion docs screen-ui`; a bad value is `L1618`, a clamped width `L2304`), `shadow: Option<{offset, color, softness}>` (none; a copy of the ink under it, `softness` default `0`, SDF only, `ludion docs screen-ui`; a bad value is `L1622`, a bitmap softness `L2307`) |
| `UiList` | `anchor`/`offset`/`title`/`items: [{text, enabled}]` (empty — draws nothing)/`selected: u32`/`max_visible: u32` (`0` = unlimited — windows the drawn items around `selected`)/`size: f32` (`24.0`, `L1118`)/`line_spacing`/`padding: f32` (`0.0`/`16.0`, `>=0`)/`color`/`selected_color`/`disabled_color`/`background: [f32;4]`/`font: Option<String>` (as `UiText`)/`order: i32`/`visible: bool` (`true`) — the selectable-menu list; screen-space only. See `ludion docs ui-list`, `outline: Option<{width, color}>` (none; ink under the glyphs, `ludion docs screen-ui`; a bad value is `L1618`, a clamped width `L2304`), `shadow: Option<{offset, color, softness}>` (none; a copy of the ink under it, `softness` default `0`, SDF only, `ludion docs screen-ui`; a bad value is `L1622`, a bitmap softness `L2307`) |
| `UiRadial` | `anchor`/`offset`/`group` as `UiList`, `radius_inner` (`90`)/`radius_outer` (`220`), `start_deg` (`0`)/`gap_deg` (`2`), `items: [{text, detail, atlas, frame, enabled}]` (max 16; empty draws nothing), `selected: Option<u32>`, `pointer`, `deadzone` (`0.45`)/`hysteresis_deg` (`6`), `size` (`24`)/`icon_size` (`48`)/`font`, `color`/`selected_color`/`disabled_color`, `fill`/`selected_fill`/`stroke` (wedges; none), `order`/`visible`/`outline`. Invalid: `L1619`. `ludion docs ui-radial` |
| `UiShape` | `anchor`/`offset`/`group` as `UiRect`, `shape: {type: line|circle|ring|arc|wedge|rounded_rect|polygon|polyline, ..}` (default circle, radius `16`; `polygon { points, join }` fills and/or strokes; `polyline { points, closed, join, cap }` is stroke only), `fill: Option<[f32;4]>`, `stroke: Option<{width, color}>`, `dash: Option<{on, off}>` (cuts the stroke; needs a `stroke`; a bad one is `L1621`; over 1024 dashes draws solid, `L2306`), `rotation` (`0`, degrees about the origin; non-finite is `L1620`), `order`/`visible`. Invalid: `L1621`; a degenerate polygon or polyline draws nothing (`L2305`). `ludion docs ui-shapes` |
| `SubtitleView` | `anchor` (`bottom_center`)/`offset` (`[0,-64]`)/`font`/`size` (`30`, `L1118`)/`wrap_width` (`1100`)/`max_lines` (`3`)/`speaker_label` (`true`)/`color`/`background`/`padding` (`12`)/`channels` (all)/`order`/`visible` — the built-in block of the dialogue lines on air; draws only in a game with `.dialogue(..)`. `ludion docs dialogue` |
| `UiTween` | `tracks: [{field, from, to, start (0), duration (1 s), ease (linear), repeat (once), clock (real)}]` — closed-form opacity/offset/scale/rotation/size/colour animation of a `UiRect`/`UiText`/`UiList` on the same entity; arity, non-finite or negative `duration` is `L1610`, an unsupported field `L2300`. See `ludion docs ui-tweens` |
| `UiWorldAnchor` | `target: EntityId` (required), `world_offset: [f32;3]`, `show` (`always`/`on_screen`/`off_screen`), `behind` (`clamp`/`hide`), `margin` (`48`), `fade: Option<[near, far]>`, `rotate_toward` (`false`), `distance_scale: Option<[near, far, scale_near, scale_far]>`, `camera: Option<EntityId>` — pins the element to a 3D target and clamps it to the screen edge; a bad number is `L1611`. See `ludion docs ui-world-anchor` |
| `UiGroup` | `anchor`/`offset`/`size` (as `UiRect`), `scale` (`1`, `>0`), `rotation` (`0`, degrees clockwise about the box centre, composed onto descendants and the clip), `opacity` (`1`, `0..=1`), `visible` (`true`), `group: Option<EntityId>`, `clip` (`none`/`rect`/`circle`/`rounded_rect: {corner_radius}`, cuts descendants to the box; a negative radius is `L1614`, a third clipping group in a chain `L2303`) — draws nothing; `UiRect`/`UiText`/`UiList`/`UiGroup` with `group: <ref>` anchor in its box and take its scale, opacity and visibility; `UiRect.fill_group` covers the box. A bad `scale`/`opacity` is `L1614`, a cycle `L1615`, a chain past 8 `L1616`, an ignored field `L1617`, an unresolved group `L2302`. See `ludion docs ui-groups` |
| `Text` | `text: String` (`""`), `size: f32` (`1.0`), `color: [f32;4]` (white; RGB `>=0`, alpha `0..=1`: `L1263`), `font: Option<String>` (as `UiText`), `key`/`args` (as `UiText`; `ludion docs localization`) |

**World `Text` draws on top of the scene with no depth test, in scene order** — a wall in front of a label does not hide it, and two overlapping labels stack by entity order, not by distance. Fog, beams and DoF use the label's own distance, so a label seen through a wall is fogged as far as it actually is.
