Ludion editor — six design directions

Same tool, same state (breakout scene, edit mode, brick_07 selected) — six visual identities. Specs in BRIEF.md and DIRECTIONS.md.

  1. 1BathyscapheSubmersible console: abyss dark, sodium-amber instruments, WorldHash as a cockpit gauge.
  2. 2WireInk-on-paper light UI with a bottom dock streaming the actual protocol conversation.
  3. 3GraphiteQuietest studio dark; the chrome changes temperature with mode — edit is warm, play is cool.
  4. 4Drafting tableCAD drafting film: title-block panels, dimension-line callouts measuring the selection.
  5. 5CanonText-is-truth: the selection's canonical YAML with a live minimal-diff gutter beside the viewport.
  6. 6ModelineTiling-WM density: keycap panels, all-mono type, a vim-style modeline carrying the session.
