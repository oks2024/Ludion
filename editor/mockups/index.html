Ludion editor — design directions

The same product in every mock: the Level Designer view, a live vigil session, and the terminal drawer hosting per-view Claude instances. Only the design language changes.

Round 2 — modern product language

  1. 06 · Halo Canvas-first: the rendered scene runs edge-to-edge and every panel floats above it as frosted glass — Rive/Spline energy, minimal chrome.
  2. 07 · Meridian Linear-grade layered monochrome, keyboard-first — shown with the command palette open: every capability is a command, made visible.
  3. 08 · Ensemble AI-native presence cockpit — Figma-multiplayer for human + Claude world-building: collaborator rail, agent work-regions in the viewport, live command ticker.
  4. 09 · Prism One living gradient thread — teal→violet→magenta — carries selection, meters, and the active view through an otherwise calm dark UI.
  5. 10 · Slate Zed-class dense speed tool — warm graphite, borderless separation, 4px grid, and a live frame-time sparkline in the status bar.

Round 1 — concept metaphors (set aside)

  1. 01 · Pressure Vessel The Cartesian diver as an instrument — glass plates, phosphor data, brass hardware, gauge dials.
  2. 02 · Cyanotype The whole app as a technical blueprint — Prussian blue, white ink, dimension lines, title block.
  3. 03 · Guildhall The tool wears the game's world — lantern-lit workshop, timber, brass nameplates, XP-bar meters.
  4. 04 · Plaintext Text-as-truth taken literally — the editor as one annotated document; the inspector is YAML.
  5. 05 · Fascia Braun instrument fascia — light machined gray, switchgear, one signal orange, dark terminal bay.
